# Mockups comerciais — Aluguel

Criados em 22/07/2026 a partir dos renderizadores reais do aplicativo e de uma base demonstrativa sem dados pessoais reais.

## Arquivos editáveis

- `capture/`: ambiente seguro que carrega as telas reais com dados fictícios.
- `mockups.html` e `mockups.css`: composições comerciais editáveis.
- `screenshots/`: capturas originais, sem molduras.
- `finais/`: mockups finais exportados em PNG.

## Variações

Abra `mockups.html?mockup=hero`, `portfolio`, `finance` ou `portal`.

O selo “Demonstração · dados fictícios” é deliberado: ele torna explícito que as telas preservam privacidade e não representam uma carteira real.
